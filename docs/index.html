MVG Abfahrtsdisplay – Web-Installer

Firmware direkt aus dem Browser aufspielen und das WLAN einrichten – ohne Arduino IDE.

Vorabversion: Diese Seite gehört zur Entwicklung von Version 2.0 und dient zum Testen. Für den Alltag bitte noch die Anleitung in der README verwenden.

Das brauchst du

  • USB-C-Kabel, das Daten überträgt (reine Ladekabel funktionieren nicht)
  • PC oder Mac mit Chrome, Edge oder Firefox (ab Version 151) – nicht Safari, nicht am Handy
  • WLAN mit 2,4 GHz und dessen Passwort

Dieser Browser kann nicht auf USB-Geräte zugreifen. Bitte Chrome, Edge oder Firefox (ab Version 151) am PC oder Mac verwenden.

Der Installer funktioniert nur über eine sichere Verbindung (https).

Firmware-Version wird geladen …

Der Installer-Dialog ist englisch – die Schritte unten zeigen, was wo zu klicken ist.

So geht’s

Erste Einrichtung
  1. Display per USB anstecken und oben auf Installieren klicken. Firefox fragt vorher, ob die Seite auf serielle Geräte zugreifen darf – erlauben.
  2. Im Browser-Fenster das Gerät wählen (meist USB JTAG/serial debug unit) und Connect klicken.
  3. Install MVG Abfahrtsdisplay wählen, Erase device anhaken und bestätigen. Das Aufspielen dauert etwa eine Minute.
  4. Connect to Wi-Fi: WLAN wählen, Passwort eingeben.
  5. Visit device öffnet die Einstellungen des Displays. Dort die Station suchen, auswählen und speichern – fertig.

Solange keine Station gespeichert ist, zeigt das Display einen QR-Code und die Adresse der Einstellungen.

Update auf eine neue Version
  1. Display per USB anstecken, Installieren klicken, Gerät wählen.
  2. Update MVG Abfahrtsdisplay klicken. Station, WLAN und alle Einstellungen bleiben erhalten.

Alternativ ohne Kabel: Firmware-Datei im Einstellungsportal hochladen (siehe README).

WLAN ändern

Display per USB anstecken, Installieren klicken, Gerät wählen und Change Wi-Fi wählen. Die übrigen Einstellungen bleiben erhalten.

Das Display wird nicht gefunden
  • Anderes USB-Kabel oder einen anderen USB-Anschluss probieren.
  • Notlösung: die Taste BOOT gedrückt halten, während du das Kabel einsteckst, dann erneut Installieren. Nach dem Aufspielen das Kabel einmal ab- und wieder anstecken, dann Installieren → Connect to Wi-Fi.

Anleitung, Bedienung und Hilfe: README auf GitHub

Die Abfahrten stammen aus der inoffiziellen, nicht dokumentierten MVG-Schnittstelle. Sie kann sich jederzeit ändern oder abgeschaltet werden. Kein offizielles Angebot der MVG.
